# bandplot

> **Deprecated — no longer maintained.**
> Everything `bandplot` used to do now lives in
> [**mcta**](https://github.com/lkccrr/mcta) (Meta Crystal Toolkit & Analysis).

`bandplot` is kept on PyPI only so that existing environments break loudly instead
of silently running stale code. Since 0.3.0 the distribution ships no code at all:
`import bandplot` raises `ImportError` with a pointer to the replacement.

## Migrate

```bash
pip install mcta      # or pip install "mcta[all]"
mt --help
```
